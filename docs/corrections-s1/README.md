# Corrections enseignant — semestre 1

Ces éléments sont séparés des énoncés et ne sont pas publiés comme pages du site. Les démonstrations des cours illustrent les notions ; elles ne constituent pas une remise intégrale des exercices notés.

## Intégration

INT-02 : document complet, header/nav/main/footer, sections titrées, trois articles, liens vers id uniques. INT-03 : feuille chargée, sélecteurs de classe, boîte expliquée et Flexbox appliqué au parent. INT-04 : corriger le chemin CSS, l'orthographe de classe, la priorité concurrente et l'image trop large, puis enregistrer les fichiers. INT-05 : trois colonnes avec repeat(3, 1fr), six cartes donnent deux lignes ; 1 / 3 occupe deux colonnes.

INT-06 : comparer la remise au cahier des charges des six profils ; le HTML doit rester lisible sans CSS. INT-07 : conteneur limité et centré, palette cohérente, classes partagées, nav flex et liste grid. INT-08 : base une colonne, query à 700 px, focus visible, six tests documentés. Il existe plusieurs solutions correctes : ne pas imposer une identité visuelle unique.

## PHP

DEV-02 : panier quantité × prix puis réduction si total >= 30 ; trois traces indépendantes. DEV-03 : correction intégrale dans tarif.php ; sorties 0/invalide, 1/12, 3/36, 4/42, 6/66, 7/invalide. DEV-04 : correction dans profils.php ; total 35, moyenne 35/3 formatée, garde count > 0, affichage de noms échappés.

DEV-04 : trois exercices autonomes de tournoi, boutique et sélection d’activités ; aucun objet PHP. Les notions évaluées sont parcours, accumulation, candidat maximal, sélection et rendu textuel. `profils.php` reste un exemple enseignant de parcours et d’échappement.

DEV-05 : connexion avec comptes fictifs en clair, comparaison stricte, identité en session, accueil protégé et déconnexion. DEV-06 : réutiliser cette identité pour un mini-chat avec historique dans un fichier texte commun. La référence exécutable et ses instructions se trouvent dans [messagerie](messagerie/README.md). Vérifier absence de doublon au rechargement, auteur issu de la session, historique partagé et conservation des messages après déconnexion. Le TP final dure 90 minutes, sans remise différée. Les énoncés n’incluent aucun programme de départ.

## Projet de site

SITE-01 : public, trois tâches, périmètre, plan et critères vérifiables. SITE-02 : distinguer wireframe/maquette/prototype, relever relations, tokens et questions d'état. SITE-03 : document sémantique, navigation réelle, crédits. SITE-04 : parent grid pour cartes, parent flex pour liens, conteneur fluide. SITE-05 : valeurs communes et variantes limitées. SITE-06 : base mobile, queries justifiées, contenus préservés. SITE-07 : audit clavier/labels/alternatives/contraste et tests manuels. SITE-08 : dossier autonome et démonstration d'un parcours avec preuve d'une correction.

Évaluer les sites sur les critères annoncés, plutôt que comparer chaque pixel à un unique corrigé. Les liens publics vers les références restent autorisés selon les modalités de l'enseignant.
