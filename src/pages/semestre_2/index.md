Le S2 réutilise HTML, CSS et PHP du S1. Les classes Tailwind expriment des règles CSS déjà connues ; les interactions JavaScript précèdent les échanges HTTP/JSON et le CRUD MySQL. Le portfolio assemble ensuite lecture, rendu, filtres, gestion et vérification des données.

Les QCM disponibles permettent de réviser les notions du support précédent : dix questions sont tirées, avec vingt secondes par question et la possibilité de recommencer.

## Projets PHP/MySQL
