## Les éléments HTML : texte, liste et lien

Les ressources de cette page sont facultatives. Le [cours HTML](/semestre_1/integration/htmltd) explique d’abord la syntaxe et les rôles ; les jeux permettent ensuite de vérifier un choix de balise.

```html preview title="Une liste possède des éléments li" height=170
<h2>Domaines MMI</h2>
<ul><li>Développement web</li><li>Création visuelle</li></ul>
<a href="#suite">Suite</a>
<p id="suite">Les domaines se complètent dans les projets.</p>
```

Le titre introduit la liste, chaque `li` forme une entrée et le lien rejoint une destination réelle. Changer `ul` en `ol` afficherait une liste numérotée : ce choix dépend du sens de l’ordre, pas seulement de la décoration.
