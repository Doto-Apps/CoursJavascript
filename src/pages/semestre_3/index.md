Le S3 s’appuie sur les objets JavaScript, les échanges HTTP/JSON et la persistance du S2. Retool relie composants, requêtes et documents Firebase. En Déploiement de services, vous créez une API avec Express, affichez ses données dans le navigateur puis réalisez le projet final Alter Ego : un chatbot qui présente votre profil et votre personnalité à l’aide d’une API de modèle de langage.

Les QCM disponibles permettent de réviser les notions du support précédent : dix questions sont tirées, avec vingt secondes par question et la possibilité de recommencer.
